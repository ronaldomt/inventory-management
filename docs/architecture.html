Factory Inventory Management System

Architecture, tech stack and data flow. Vue 3 frontend, FastAPI backend, JSON files as the data store.

System architecture

Tech stack

Frontend

  • Vue 3.5 (Composition API)
  • Vue Router 4
  • Axios
  • Vite 8, dev server on port 3000
  • Plain CSS, custom SVG charts
  • i18n: English and Japanese

Backend

  • Python 3.11 or newer
  • FastAPI + uvicorn, port 8001
  • Pydantic 2 response models
  • uv for dependencies
  • No database, no auth on the API

Tooling

  • pytest + FastAPI TestClient (tests/backend)
  • Claude Code config in .claude/: 3 agents, 6 commands, 1 skill, 1 hook
  • MCP servers in .mcp.json: Playwright, GitHub

Data flow

  1. The user changes a filter in the filter bar (Time Period, Location, Category, Order Status). The values live in useFilters.js as shared state.
  2. A view calls a method in api.js. The method adds the active filters as query parameters.
  3. Axios sends the request to http://localhost:8001/api/.... The address is fixed in api.js.
  4. FastAPI filters the Python lists that mock_data.py loaded from the JSON files at start-up.
  5. Pydantic checks the result against the response model. FastAPI returns JSON.
  6. The view stores the raw data in refs. Computed properties build the cards, tables and charts.
